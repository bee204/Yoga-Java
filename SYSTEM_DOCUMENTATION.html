Hướng Dẫn Cài Đặt & Khởi Chạy Từng Bước Dành Cho Người Mới

Chỉ cần làm đúng theo 5 bước dưới đây là hệ thống sẽ chạy 100% trên máy của bạn.

1

Kiểm tra Môi Trường Java (JDK 17) & Maven

Mở cửa sổ PowerShell hoặc Command Prompt và kiểm tra phiên bản:

# Kiểm tra Java (yêu cầu Java 17 trở lên): java -version # Kết quả: openjdk version "17.0.21" ... # Kiểm tra Apache Maven (yêu cầu Maven 3.8+): mvn -version # Kết quả: Apache Maven 3.9.9 ...

* Lưu ý: Nếu báo lệnh không tìm thấy (CommandNotFound), hãy đảm bảo thư mục bin của JDK và Maven đã được thêm vào biến môi trường PATH của Windows.

2

Bật MySQL trên XAMPP Control Panel

Mở ứng dụng XAMPP Control Panel trên máy tính của bạn và bấm nút Start ở dòng MySQL (đảm bảo hiển thị cổng 3306 màu xanh lá).

Cơ sở dữ liệu mặc định là yoga_management. Hệ thống đã được cấu hình cờ tự động tạo database nếu chưa có: createDatabaseIfNotExist=true.
3

Kiểm tra File Cấu Hình Database (application.properties)

File cấu hình nằm tại đường dẫn: src/main/resources/application.properties:

# Cổng chạy ứng dụng server.port=8080 # Kết nối MySQL XAMPP spring.datasource.url=jdbc:mysql://127.0.0.1:3306/yoga_management?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC&characterEncoding=UTF-8 spring.datasource.username=root spring.datasource.password= spring.jpa.hibernate.ddl-auto=update

Khi học viên đăng ký hoặc khi Admin bấm "Phê duyệt", hệ thống tự động đếm số lượng học viên CONFIRMED. Nếu đã đạt sĩ số tối đa của lớp, hệ thống lập tức chặn lại và báo thông báo rõ ràng.

Cấu Trúc Bảng Dữ Liệu Quan Hệ (MySQL 8.x)

Mô hình dữ liệu 7 thực thể được quản lý bởi Spring Data JPA & Hibernate

Bảng (Table) Khóa chính (PK) Khóa ngoại (FK) Ý nghĩa nghiệp vụ
users id (BIGINT) teacher_id, customer_id Lưu thông tin đăng nhập, mật khẩu BCrypt, vai trò (admin, teacher, customer).
teachers id (BIGINT) - Hồ sơ giảng viên: Họ tên, điện thoại, email, ngày sinh, kinh nghiệm, avatar.
classes id (BIGINT) teacher_id Lớp học: Tên lớp, giờ bắt đầu/kết thúc, lịch tập, phòng học, học phí, sĩ số max.
customers id (BIGINT) - Hồ sơ học viên: Họ tên, số điện thoại, email, địa chỉ, giới tính.
registrations id (BIGINT) customer_id, class_id Đơn đăng ký gói tập: Số tháng, chiết khấu, giá cuối, trạng thái (PENDING/CONFIRMED).
attendances id (BIGINT) registration_id Sổ điểm danh theo ngày: Ngày tập, trạng thái (PRESENT, ABSENT, EXCUSED).
class_reviews id (BIGINT) class_id, customer_id Đánh giá chất lượng: Số sao (1-5), nội dung nhận xét của học viên.
